# Side Cart Pro

Modern slide-in WooCommerce side cart.

## Installation and use

Place the `side-cart-pro` directory in `wp-content/plugins/` and activate **Side Cart Pro** from the WordPress Plugins screen.

Activate WooCommerce to enable the slide-in cart integration.
